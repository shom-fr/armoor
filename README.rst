Armoor - Analysis of Regional MOdelised and ObseRved ocean
##########################################################

Armoor is a python library for helping analysis of regional modelised and observed ocean.

- Documentation

        The documentation is generated and hosted by gitlab-pages:
        https://gitshom.gitlab.io/STM/armoor/

- Sources and help

        Sources are available on the sloop gitlab page:
        https://gitlab.com/GitShom/STM/armoor.
        Here you can also post tickets for requests and issues.
