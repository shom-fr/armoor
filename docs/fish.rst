Fish interface
==============

.. meta::
    :description: Installation process for fish interface (ShomUi)

This project was generated with `Angular CLI <https://github.com/angular/angular-cli>`_ version 13.2.5.


Development server
------------------

Run ``ng serve`` for a dev server. Navigate to ``http://localhost:4200/``. The app will automatically reload if you change any of the source files.

Build
-----
Run ``ng build --configuration=production`` to build the project. The build artifacts will be stored in the ``dist/`` directory.

Further help
------------

To get more help on the Angular CLI use ``ng help`` or go check out the `Angular CLI Overview and Command Reference <https://angular.io/cli>`_ page.
