.. _guides:

In-depth guides
###############

The :ref:`howtostart`, :ref:`cli` and :ref:`accessors` pages describe *what*
each executable, accessor or configuration key does. The guides below
instead explain *how the pieces fit together* -- the concepts, internal
mechanisms and gotchas that cut across several executables and are easy to
miss when reading the reference pages in isolation.

Read the :ref:`tutorials` first if you have never run armoor before; come
back here once you hit a design choice you want to understand more deeply.
