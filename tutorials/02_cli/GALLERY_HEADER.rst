Command-line tools
===================

These tutorials drive armoor's metazone-based executables -- ``armoor-data``
and the ``armoor-comp-*`` family (``-argo``, ``-sst``, ``-drifter``,
``-mooring``, ``-models``, ``-clim``, ``-hydrosection``) -- each one writing
a real ``data.cfg``/``metazones.cfg`` pair and running the actual command,
the same way you would from a shell.
