.. _tutorials:

Tutorials
=========

These tutorials are plain Python scripts, executed and rendered as a gallery
as part of the documentation build. Every page can be downloaded and re-run
locally either as a ``.py`` script or as a Jupyter ``.ipynb`` notebook -- use
the links at the bottom of each page.

They come in two groups: :ref:`tutorials_library`, which walk through the
**Python API** (:ref:`accessors`) directly, and :ref:`tutorials_cli`, which
drive the metazone-based executables (``armoor-data``, ``armoor-comp-*``).
All of them run on small datasets -- synthetic, or bundled with armoor's own
test suite -- that need no network access or external download. The
:ref:`examples` gallery is the companion reference for ready-to-run
configuration files, without the narration.
